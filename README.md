# موقع وبوابة مديري المدارس (Principals Portal)

هذا المجلد `website` يحتوي على موقع الويب الكامل والمستقل المخصص لمديري المدارس، والمبني للعمل مباشرة عند رفعه على أي خادم استضافة أو دومين خاص (Static Web Hosting, Nginx, Apache, Vercel, Netlify, Cloudflare Pages, cPanel).

---

## 🌟 مميزات موقع وبوابة المديرين

1. **تصميم متكامل باللغة العربية واتجاه RTL** بهوية وزارة التعليم بالمملكة العربية السعودية وخط «Cairo» مع تصميم عصري متجاوب لكافة الشاشات (الهواتف، الأجهزة اللوحية، والشاشات المكتبية).
2. **تسجيل دخول آمن لمدير المدرسة**:
   - الدخول باستخدام رقم الهوية الوطنية / اسم المستخدم وكلمة المرور.
   - حفظ الجلسة على الجهاز والتحقق منها.
3. **رصد وإدارة الشواهد للمعايير الـ 19 المعتمدة رسمياً**:
   - اختيار المعيار من بين العناصر الـ 19 الرسمية المعتمدة (بما فيها معيار نافس رقم 13 بوزنه النسبي 10%).
   - إمكانية رفع روابط سحابية، نصوص توثيقية، وملفات ووثائق.
   - إمكانية حذف الشاهد وتعديله بسهولة.
4. **خطة التحسين النصف سنوية**:
   - خاصة بالتقييم النصف سنوي فقط وفقاً لضوابط النظام.
   - رصد الأهداف التطويرية والإجراءات العلاجية والبرامج المقترحة لمعالجة الفجوات.
5. **كشف الدرجات والنتائج المعتمدة**:
   - عرض فوري للدرجة النهائية والتقدير العام المعتمد.
   - جدول تفصيلي بكافة درجات المعايير وملاحظات وتوصيات المقيم.
   - زر مدمج لطباعة التقرير الرسمي مباشرة بصيغة احترافية.

---

## 🚀 طريقة الرفع على الدومين والاستضافة

### 1. الرفع المباشر على خادم الويب (cPanel / Apache / Nginx / Plesk)
* ارفع محتويات فولدر `website/` (ملف `index.html` و `app.js`) مباشرة داخل مجلد `public_html` أو مجلد الدومين الفرعي (مثل `portal.yourdomain.com`).
* سيعمل الموقع فوراً بدون الحاجة إلى تثبيت أي حزم أو تشغيل Node.js على الخادم، نظراً لاعتماده على تقنيات الويب القياسية.

### 2. الرفع على المنصات السحابية المجانية (Vercel / Cloudflare Pages / Netlify)
* اختر مجلد `website` كمجلد الجذر للمشروع (Root Directory).
* الأمر الخاص بالبناء: اتركه فارغاً.
* مجلد الإخراج (Output Directory): `.` (المجلد الحالي).

---

## 🔄 آلية المزامنة والربط مع التطبيق المكتبي (Desktop App)

1. **العمل بدون إنترنت (Offline-First)**:
   - يحفظ الموقع مدخلات المدير محلياً ويظل يعمل حتى في حال انقطاع الشبكة.
2. **الربط المشترك بقاعدة البيانات / الخادم السحابي**:
   - يرتبط الموقع والتطبيق المكتبي عبر جدول `sync_queue` وواجهة برمجية موحدة.
   - عند توفر الإنترنت، يتم نقل الشواهد وخطط التحسين المرفوعة على الموقع إلى التطبيق المكتبي فوراً، وتُحدّث درجات المدير المعتمدة من التطبيق لتظهر على صفحته بالموقع.

---

## 🔒 الأمان وحماية البيانات
* لا توجد أي كلمات مرور أو مفاتيح سرية مكشوفة داخل ملفات الواجهة.
* جميع المعاملات وتوثيقات الرفع تسجل في سجل التدقيق (Audit Log).
